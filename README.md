# Griha Estates – Real Estate Listing Website

Gen AI Assessment 1 – Project #26 (NIAT × Geeta University).

## Features
- Property listings (12 properties, cards + detail popup)
- Filters: search, location, type, minimum area, bedrooms, max price, sorting
- Saved favourites (stored in browser localStorage, "Saved" view)
- Inquiry form with validation, optional pre-filled property

## Tech
HTML5, CSS3, vanilla JavaScript. No build step.

## Run
Open `index.html` in a browser, or deploy the folder on Vercel / Netlify / GitHub Pages.
